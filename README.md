# RegexPilot Issues

This is the public issue tracker for [RegexPilot](https://regexpilot.app) — a visual regex builder for macOS. The app's source code is private; this repo exists so users can report bugs and request features publicly.

## Reporting a bug

[Open a bug report](https://github.com/Kristofp/regex-pilot-issues/issues/new?template=bug_report.md)

Please include:
- Your RegexPilot version (Settings → About)
- macOS version
- The regex flavor you were using (if relevant)
- Steps to reproduce

## Requesting a feature

[Open a feature request](https://github.com/Kristofp/regex-pilot-issues/issues/new?template=feature_request.md)

## Before you file

- Search existing issues — someone may have reported the same thing
- For urgent account/billing issues, use support@regexpilot.app instead
